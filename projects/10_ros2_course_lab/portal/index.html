② 明日课件 · Gazebo 世界、模型与 ROS2 桥接

1世界（World）

一个 .sdf 文件 = 物理参数 + 模型实例 + 插件。课堂用 arena_w12.sdf：10×10 m 场地、L 形内墙、1 ms 步长、RTF 1.0。

gz sdf -p worlds/arena_w12.sdf > /tmp/norm.sdf
gz model --list
gz sim -r -v2 worlds/arena_w12.sdf
静态墙必须写 <static>true</static>，否则被车撞飞。

2模型（Model）

URDF/Xacro 描述机器人本体：link + joint + visual + collision + inertial。缺 inertial 必抖，轮关节必须 continuous 且 rpy=π/2。

xacro diffbot_sim.urdf.xacro > /tmp/r.urdf
check_urdf /tmp/r.urdf
ros2 launch urdf_tutorial display.launch.py model:=/tmp/r.urdf
RViz 只出 base_link？缺 robot_state_publisher 和 joint_state_publisher。

3桥接（Bridge）

ros_gz_bridge 把 Gazebo 的 gz.msgs.* 与 ROS 2 的 *.msgs::* 一一映射。时钟只能有一个发布者。

ros2 run ros_gz_bridge parameter_bridge \
  --ros-args -p config_file:=$HOME/ros2_ws_w12/src/week12_odometry/config/bridge_w12.yaml
ros2 topic info /clock | grep -i publisher
Jazzy 的 /cmd_vel 收 TwistStamped；CLI 发布时多套一层 twist.twist 会全零且不报错。

远程 PC 连 DGX —— 账号是 nvidia

结论：SSH 服务没坏。你试的 7 个用户名里，只有 nvidia 真实存在；ubuntu/lzp/spark/dgx/admin 是 Invalid user（日志实证），root 被 PermitRootLogin without-password 设计拒绝。

# 密码登录（已实测 1.3 s 通）
ssh @      # 密码：
ssh @     # 局域网同样通

# 免密登录（推荐，已装公钥并验通）
ssh -i  @
对方 PC 先把 私钥放到自己机器（权限 600），Windows 用 ssh -i .\ @。若不在同一 tailnet，必须先让对方 PC 加入同一个 tailnet。
