05 / IRON RULES

5 条踩坑铁律（全部实测查证）

这一节是本次最有复用价值的部分。每一条都写清了「现象 → 根因 → 判定方法 → 修复」， 并且都是在真实命令输出上确认过的，不是推测。

RULE 01

默认 experience 启动即段错误（EXIT=139）

现象：SimulationApp({"headless": True}) 不传 experience，进程在启动阶段直接 段错误，第一步 print 都执行不到；但单独 import osqp 完全正常（0.6.7.post3）。
根因：默认 isaacsim.exp.full.kit 会 startup isaacsim.robot.wheeled_robots，其 holonomic_controller.py 导入 osqp 的编译扩展 _osqp.cp310-win_amd64.pyd， 在全量 Isaac DLL 已加载后初始化即访问违例。
为什么训练不崩：Isaac Lab AppLauncher 在 headless 且无相机时用的 isaaclab.python.headless.kit 不含 wheeled_robots。
修复：自定义 kit，机械臂分拣根本用不到轮式机器人。

RULE 02

物理不写回 USD → 录像是一张静止图

现象：仿真状态正常推进（末端从 z=0.30 降到 0.09 再飞到分拣箱）， 但录出的视频里机械臂一动不动；逐帧比对 MAE=1.5、变化像素仅 7.7%，全是压缩噪声。
根因：isaaclab.python.headless.rendering 基线把 physics.updateToUsd、fabricUpdateTransformations 全设成 false（为 RL 吞吐提速）。RTX/Hydra 读到的永远是初始姿态。
修复：kit 里显式打开 updateToUsd=true / fabricUpdateTransformations=true， 并在脚本里内置「与首帧差异」逐 300 步打印作为回归护栏。

RULE 03

状态机相位时长不足 → 夹爪在空中闭合

现象：反复打印 Object Dropped Mid-Air!， 诊断日志显示末端一路下降但只到 z≈0.096，夹爪就闭合到 0.0000。
根因：原仓库用 Franka 默认 events_dt[1]=0.005，phase1 只有 200 步； 本机 RMPFlow 下降速度约 0.0012 m/步，从 h1=0.3 降到方块中心（z≈0.02） 需要约 255 步 —— 差 55 步，夹爪正好在方块上方 7 cm 处合拢。
修复：events_dt[1] 0.005 → 0.0025（400 步）。 改后末端降到 0.089，夹爪闭合到 0.0406（夹住了），方块 z 从 0.02 抬到 0.0999。

RULE 04

OpenCV 4.x 在 Windows 上写不了中文路径

现象：cv2.imwrite(r'E:\研究生学习\...\_t.png', img) 返回 False 静默失败；cv2.VideoWriter 同路径 isOpened()=True 但只落一个 258 字节的空壳文件。
根因：OpenCV 内部用 ANSI fopen，非 UTF-8 路径直接失败。
修复：所有 OpenCV 落盘先写 %TEMP%/isaac_arm_stage（纯 ASCII）， 收尾用 shutil.move 搬到中文目录。

RULE 05

Isaac Camera 的坐标约定与焦距都和 USD 常识不同

坐标：set_world_pose 默认 camera_axes="world" 语义是 +X 朝前 / +Z 朝上，而 USD 标准相机是 -Z 朝前 / +Y 朝上。 传 USD 四元数会被再叠一层旋转 → 画面横滚、地平线变竖直。必须显式 camera_axes="usd"。
焦距：默认焦距极短（实测约 4.2 mm，水平视场仅 ~29°）， 按 USD 常识设 17 mm 反而变成 hFOV=7.1° 的长焦。 正确做法是按目标视场反算： focal = horizontal_aperture / (2·tan(hfov/2))。
另：不要用 Gf.Matrix4d().SetLookAt().ExtractRotationQuat()， 那是 world→camera 视图矩阵，取出的是逆旋转（实测整幅全黑）。

RULE 06

两个隐蔽的坑：变量遮蔽 与 headless 下的「假死」

变量遮蔽：main() 里写 stage = world.stage 会遮蔽模块级的 stage() 函数，触发 UnboundLocalError: local variable 'stage' referenced before assignment —— 因为 Python 在函数入口就把 stage 判定为局部变量。 函数改名为 stage_path() 即可。
假死：若脚本以 while simulation_app.is_running(): sim.step() 结尾， headless 模式没有窗口可关，is_running() 永远为 True。 判定是否为真死锁不要看 CPU，要看 IO 计数器增量：静置 20 s 内 ReadOperationCount 增量为 0 即确认未在推进。
