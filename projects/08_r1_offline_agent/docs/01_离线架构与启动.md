# 1. 离线架构与启动

## 离线意味着什么

| 维度 | 在线 Agent | 本离线 Agent |
|---|---|---|
| 知识来源 | 联网检索 / 云端向量库 | 本地 `memory/kb_*.json`（BM25 倒排） |
| 推理 LLM | 云端 API | 本地 Ollama（127.0.0.1），无则检索模板兜底 |
| 外联 | 任意 HTTP | `guard.py` 拦截一切非回环连接 |
| 记忆 | 云端 | 本地 `verified.jsonl` / `recheck.jsonl` |
| 上线 | 人工发布 | 本地门控 `go_live`（≥30天 & 精确率≥0.90 & KB≥200） |

## 启动链路

```
start.py
  ├─ install_guard(strict=True)        # 离线护栏: 非 127.0.0.1 连接被拒
  ├─ boot_kb()                         # 载入/构建知识库(corpus/ -> memory/)
  ├─ Agent(kb)                         # 闭环: 检索 -> 合成 -> 校验 -> 决策
  ├─ run_loop()  [--loop]              # 20h 内测窗口(默认72000s)
  └─ serve()     [--web]               # 127.0.0.1:18941 控制台
```

## 依赖

仅 Python 3.9+ 标准库。**无需 pip 安装任何包**，因此断网也能完整跑。
若想让问答更自然，联网时 `ollama pull qwen2.5:7b` 一次，之后离线调用本地模型。
