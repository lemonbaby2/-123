# 2. 自学习机制与上线门控

## 每日 20h 内测（Action 试错）

`core/selflearn.py::run()` 在 `budget_seconds`（默认 72000 = 20h）窗口内，
对 `tasks/sample_tasks.jsonl` 循环执行：

```
for 每个任务:
    res = agent.understand(query)         # 检索 -> 合成 -> 自我校验
    if res.verified:
        追加 memory/verified.jsonl        # 正确: 记忆回去
    else:
        追加 memory/recheck.jsonl         # 错误: 标原因, 待复核
    累计 state.json (day/iterations/correct/wrong)
```

- 窗口用 `dt.datetime.now()` 计时；跨午夜自动 `day += 1`，符合「每天」语义。
- DGX 上由 `dgx/r1-offline-loop.{service,timer}` 每天 02:10 触发，与 R1 Forge 夜窗错峰。

## 对错分流

| 结果 | 落盘 | 含义 |
|---|---|---|
| verified=True | `verified.jsonl` | 答案有依据（词元重叠≥8%），固化 |
| verified=False | `recheck.jsonl` | 无依据/拒答/空洞，标记原因 |

## 复核（reconcile）

知识库随 `ingest` 增长后，历史上「错误」项可能变「正确」。
`python start.py --reconcile` 对 `recheck.jsonl` 逐条重新 `understand`，
通过则移入 `verified.jsonl`（保留 `corrected_answer`）。

## 上线门控（launch gate）

```
go_live = (day >= 30) and (precision >= 0.90) and (kb_size >= 200)
precision = correct / (correct + wrong)
```

- 不满足条件 → `go_live=False`，继续内测吸收。
- 满足 → 标记 `state.go_live=True`，可「完整启动」对外服务。
- 门控参数在 `selflearn.py` 顶部常量，可按需收紧。

## 为什么这样设计

- **不伪造训练结果**：窗口只做真实试错与记忆，从不在无依据时宣称「学会」。
- **错误可审计**：每条 recheck 都带 `verify_reason`，便于人工核对清晰。
- **渐进可信**：用「精确率 + 天数 + 规模」三重闸门，避免小样本过拟合式「上线」。
