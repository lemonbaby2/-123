# 3. 与「每日 VLA 验收公网门户」的关系

两条交付是**同一个机器人的离线与在线两面**，构成闭环：

```
        ┌─────────────────────────────────────────────┐
        │  DGX 在线肌肉: dgx/r1-vla-accept            │
        │  每天 05:30 真跑 WALL-OSS-0.5 推理          │
        │  → reports/<date>/report.md + 4 张曲线      │
        └───────────────┬─────────────────────────────┘
                        │ 报告/曲线回灌进 corpus/
                        ▼
        ┌─────────────────────────────────────────────┐
        │  本离线 Agent: 大脑                          │
        │  断网答疑 + 每天20h试错 + 记忆 + 上线门控    │
        │  memory/kb + verified/recheck + state.json   │
        └─────────────────────────────────────────────┘
```

## 在线侧（已交付并验证）

- `dgx/vla_accept.py`：权重完整性/SHA256/许可/加载/动作形状/数值稳定/幅值合规 共 9 项验收。
- `dgx/vla_portal.py`：门户（127.0.0.1:18932），含 `/api/state` `/api/metrics` `/api/history` `/report` `/charts`。
- systemd 定时器：每日 05:30 自动跑，已产出 **2026-11-15 PASS（9/9）** + 4 张曲线。
- 公网：受 DGX funnel 端口（10000–10014 + 443）已全部占用于生产/ros2/Embodied Studio 限制，
  释放端口后由 `dgx/enable_public.sh` 一键公开。

## 离线侧（本包）

- 把在线侧的验收报告/研究/提问归档作为 `corpus/`，离线 agent 反复吸收、试错、记忆。
- 即使断网、无 WiFi，也能回答「WALL-OSS-0.5 参数/许可/蒸馏可行性/边缘部署」等问题，
  并对答案做依据性校验，正确固化、错误复核。

## 选型锚点（已核实）

- **唯一能真训真推**：WALL-OSS-0.5（Apache-2.0，4.16B，零样本真机就绪）。
- 参数更大但未启用：X-Planner-9B（规划器不输出动作）、WALL-OSS-1.0-lite（仅仿真）、
  WALL-WM/SS（权重未发布）、WALL-A/B（闭源）。
- 许可红线：GR00T N1.5/N1.6 不可商用，仅登记不启用。
