# 首板上电与 3S2P 接线快速清单 V1.0

日期：2026-08-03

> **禁止项：当前 BMS 不得接真实电池。** 必须先修正 BQ76920 3S VC 映射，并补交真实 BMS PCB/Gerber。主控雷达 300 W 支路和 TPS16630 R47 也必须先整改。

## 一、投板前四个硬门槛

- [ ] BQ76920 改为：VC5=B+；VC4=VC3=VC2=B2；VC1=B1；VC0=B-，并同步修改均衡网络。
- [ ] 补齐真实 BMS Gerber、钻孔、网表、BOM、CPL、叠层和装配图；当前 `BMS_PCB1_2026-08-02.pdf` 实际为主控 PCB 内容。
- [ ] TPS16630 R47 按 `IOL(A)=18/RILIM(kΩ)` 重算；166 kΩ 不可用。300 W 雷达支路必须独立重设计。
- [ ] U5/U10、R52/R53、R54/R55、CAN R1、R37 均有明确 DNP/装配变体。

## 二、主控首次上电

- [ ] 断开 UM982、MTi-3、STM32 核心板、Jetson、电机、雷达、BMS。
- [ ] 测 VBAT、5V_SYS、3V3_RTK、3V3_IMU、3V3_MCU 对地阻抗并记录。
- [ ] 12.0 V 实验电源，限流 0.10 A 接 CN5；进入限流/发热/异味立即断电。
- [ ] 测 5 V 和三路 3.3 V；确认启动、纹波和 MTi VDDA 后升至 0.30 A，再接假负载。
- [ ] 按 STM32→CAN/UART/BMS I2C→UM982→MTi→PPS→功率分支逐项装接。

## 三、BMS 模拟器上电（整改后）

- [ ] 三路隔离电源串联，每路 3.0-3.3 V、20-50 mA，构造 B-/B1/B2/B+。
- [ ] 相邻电压均为正且接近单节；累计电压单调递增。
- [ ] 采样插入：B-→B1→B2→B+；拆除反向。NC 不接。
- [ ] 唤醒后 REGOUT≈3.3 V；I2C 7 位地址 0x08；使用 CRC；写 CC_CFG=0x19。
- [ ] 先 50 mA 假负载，再 0.5 A、1 A；故障注入只用模拟器/受控治具。

## 四、3S2P 真实线束（最终验证后）

| 节点 | CN1 | 高电流线 | 说明 |
|---|---|---|---|
| B- | Pin1 CELL0_P | CN2 - / BAT_MINUS | 采样与主线独立引出 |
| B1 | Pin2 CELL1_P | 无 | 第1组正/第2组负 |
| B2 | Pin3 CELL2_P | 无 | 第2组正/第3组负 |
| B+ | Pin4 CELL3_P | CN2 + / VBAT_IN | 采样与主线独立引出 |
| NC | Pin5 | 无 | 封堵绝缘 |

受保护输出为 CN3 的 VBAT+/GND_DC，接主控 CN5；不得绕过 BMS MOS。

## 五、充电器/适配器

- 3S 锂离子：12.6 V CC/CV 专用充电器。
- 3S LiFePO4：10.95 V CC/CV 专用充电器。
- 充电电流取电芯、BMS、MOS、线束、连接器、热验证中最小允许值；未知时先按整包 0.5C 保守评估。
- 主控裸板：12 V 限流实验电源，0.10 A 起步；完整功能可先预留 3-5 A，但整机必须用 Excel 功率预算计算。
- 普通 12 V 适配器不是锂电充电器。
