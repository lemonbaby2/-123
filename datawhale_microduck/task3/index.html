算法与技能动物园 —— 这只鸭子还能怎么练

先说清一件事：官方训练栈 microduck_rl 的算法层来自 rsl_rl， 而 rsl_rl 里只有 PPO 和 distillation（rsl_rl/algorithms/ 下就这两个文件）。 所以"换算法"不是改一行参数的事，得分清哪些是现成的、哪些要自己接。

玩法落地方式能拿到什么状态
PPO 冲刺配方Mjlab-Sprint-Flat-MicroDuck（本次新增）高速直道短跑，冲 2 m/s 量级进行中
PPO + RNN（LSTM/GRU）--agent.actor.rnn-type lstm + --agent.actor.class-name RNNModel带记忆的策略：扛观测延迟、扛遮挡、实机更稳一条命令可跑
PPO + 对称性增强官方 tasks/symmetry.py + --agent.algorithm.symmetry-cfg左右对称数据增广，收敛更快、步态更规整一条命令可跑
Teacher-Student 蒸馏rsl_rl/algorithms/distillation.pyteacher 吃特权信息（真实摩擦/速度），student 只看本体感知 → 可上实机需写 runner
域随机化强度扫描BAM 舵机摩擦 / 齿轮间隙 / 控制延迟 / 电池电压sim2real 稳定性，直接决定上真鸭子会不会摔改配置即可
粗糙地形课程Mjlab-Velocity-Rough-MicroDuck / -Backlash-台阶、斜坡、缝隙；抗扰能力排队
七个现成技能Roulade（前滚翻）BallKick（踢球）Rollers（轮滑）StandUp SitStand GroundPick Spin Swizzle一只鸭子八种动作，全部是注册好的任务，直接 train <task>待跑
SAC / FastSAC需自己写 env 适配（rsl_rl 不含 off-policy）样本效率高，但这里 4096 并发下 PPO 更划算不建议先做
AMP（对抗运动先验）需自写判别器 + 参考动作数据学"像鸭子的跑"，不是"最快的跑"缺参考动作数据
一句话取舍：想让鸭子快 → 改命令范围 + 改奖励（本次做的事）；想让鸭子像鸭子 → AMP；想上真机不摔 → 域随机化 + RNN。 换 SAC/AMP 的收益在这台机器上不如先把 PPO 的命令空间和奖励配方调对。
