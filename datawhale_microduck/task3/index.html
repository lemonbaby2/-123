七、后端 API（FastAPI + SQLite）

本站由 app.py（FastAPI）单端口服务托管：静态资源 + 只读 JSON API，启动时把 validation/*.json 与 videos/*.mp4 汇总进 SQLite（data/runs.db）。

方法路径说明
GET/api/health存活与视频计数
GET/api/tasks10 个任务 + 各自视频列表（含时长/大小）
GET/api/tasks/{id}单任务详情（00–09）
GET/api/videos?min_seconds=120视频索引，可按最短时长过滤
GET/api/summary视频总数、≥120s 数量、验收 JSON 清单

启动：uvicorn app:app --host 0.0.0.0 --port $PORT
