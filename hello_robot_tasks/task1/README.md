# Task1：Isaac Sim 环境安装与基本控制

## 学习结论

G2 是轮式双臂机器人。底盘采用四轮独立转向/驱动：给定底盘坐标系速度 `(vx, vy, wz)` 后，每个轮心速度由平移速度与 `wz × r` 叠加，再转换为转向角与车轮角速度。机械臂每侧有 7 个自由度，关节控制负责执行目标角；FK 从关节角求末端位姿，IK 从目标位姿反求满足限位的关节角。底盘擅长平面大范围移动，机械臂擅长局部精细操作，综合任务通过统一坐标系、状态机与安全门控让两者协作。

Isaac Sim 的完整运行链路应包括：加载 G2 USD、创建物理世界、取得 articulation、按物理频率发送底盘/关节命令、步进仿真、从传感器和关节状态形成反馈。当前电脑没有 Isaac Sim，因此环境安装章节完成了配置核对，控制算法部分使用官方不依赖 Isaac 的纯 Python 实现实际执行。

## 控制方法简述

1. 底盘逆运动学将期望的三自由度底盘速度分配为四个转向角和四个轮速，并在超过上限时等比例缩放。
2. 轮速正运动学可用于简化里程计，估计 `vx、vy、wz` 并积分二维位姿。
3. 机械臂 FK 逐级相乘关节齐次变换；Jacobian 描述关节微分与末端速度的关系。
4. DLS-IK 使用阻尼伪逆抑制奇异点放大，并用零空间项让 7 自由度冗余机械臂远离关节限位。
5. 真正的综合控制还需要碰撞检测、轨迹时间参数化、底盘到机械臂坐标变换以及急停/超时保护。
