## 学习总结

这次 Hello-Robot 学习最重要的收获，是把“机器人会动”拆成了可验证的工程闭环。最底层不是大模型，而是坐标系、关节限位、时间同步和稳定的控制接口。G2 的四轮独立转向底盘先把 `(vx, vy, wz)` 分解为四个轮子的转向角和轮速；双七自由度机械臂则用正运动学、Jacobian 和阻尼最小二乘逆运动学连接关节空间与末端空间。两类控制对象虽然形式不同，但都必须遵守速度、加速度、碰撞和超时约束，否则上层任务规划再智能也无法安全执行。

感知与建图章节让我理解了数据如何进入决策链。图像检测的输出还不是抓取目标，必须结合相机内参、深度和外参，才能转换为机器人基座坐标下的三维位置。LiDAR 点云也要经过有限值、距离和体素过滤，再利用机器人位姿叠加到世界坐标。二维占据栅格通过射线逆传感器模型累计空闲与占用证据，适合导航；三维地图保留高度结构，适合机械臂工作空间与复杂场景，但资源消耗更高。本次我用确定性合成雷达实际运行了课程的占据栅格模块，从 3 帧数据得到 586 个占用栅格，使“建图”从概念变成了可以检查输入、输出和统计量的程序。

规划章节进一步说明了底盘与机械臂的共同点和差异。底盘主要在二维地图上使用 A* 获得全局路径，再在滚动窗口中考虑动态障碍并进行局部绕行；机械臂面对的是七维关节空间，需要同时满足 IK 可达、关节限位、连杆碰撞和自碰撞，因此采用 RRT-Connect 搜索，再进行捷径优化与时间参数化。本机离线实验中，底盘全局路径代价为 11.093 米，动态障碍触发局部绕行；机械臂 RRT-Connect 在 5 次迭代后得到路径并生成 648 个轨迹点。它们都体现了“全局可达性”和“局部可执行性”不能混为一谈。

VLM 与 VLA 章节让我认识到语义能力和动作能力也需要分层。VLM 更擅长理解图像、语言和高层意图，VLA 则必须把视觉、文本、机器人状态和动作序列对齐，直接服务于连续控制。数据采集的帧率、三相机同步、状态/动作维度、归一化统计和失败样本处理，都会影响最终策略。本次电脑没有 π0.5 权重和 Isaac Sim，因此我没有把官方 GIF 冒充本机结果，而是实际验证了 red、green、blue 三阶段 prompt 分解与 NPZ 数据记录流程。这种证据边界比“只贴一张成功图”更重要，因为它明确指出了下一步需要补齐的权重、显存、仿真相机和闭环评测条件。

最后，ACoT-VLA 和 Fast-WAM 展示了具身智能继续向动作推理与世界预测发展的方向。前沿模型并不会替代经典机器人模块，而是需要建立在可靠的感知、规划、控制和安全层之上。今后的复现应固定代码与权重版本，记录随机种子、硬件、延迟和成功率，并将一次演示与多回合统计严格区分。对我而言，这套课程真正建立的是系统观：从传感器数据到状态估计，从任务意图到路径与动作，再到反馈、故障和重新规划，每一层都应有可以重跑、可以失败、可以解释的验收证据。
