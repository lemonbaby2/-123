# Task2：G2 机器人视觉感知与建图

## 感知能力构成

视觉链路通常由相机标定、图像预处理、检测/分割、深度或点云反投影、坐标变换和控制接口组成。YOLO 输出目标类别、置信度与边界框/掩膜；后续必须结合相机内参、深度以及相机到机器人基座的外参，才能得到可用于抓取的三维目标。建图链路则把 LiDAR 点转换到 `base_link`，经过有限值/距离/体素滤波后，再随机器人位姿变换到世界坐标。

二维占据栅格使用逆传感器模型：射线经过的栅格累积“空闲”证据，末端栅格累积“占用”证据，并以 log-odds 形式融合多帧。三维建图保留高度信息，表达能力更强，但内存、计算和配准要求也更高。

## 本机建图结果

![二维占据栅格结果](../artifacts/task2_mapping_result.png)

- 复用了官方 `code_chapter8` 的 `PointCloud`、坐标变换和 `OccupancyGrid2D`。
- 输入为固定种子的合成二维 LiDAR：3 个机器人位姿、2160 个端点。
- 角度去重后实际融合 1081 条射线，生成 `162 × 162` 栅格。
- 识别 586 个占用栅格、16331 个空闲栅格。
- 原始 ROS 风格结果：[PGM](../artifacts/task2_occupancy_grid.pgm)、[YAML](../artifacts/task2_occupancy_grid.yaml)、[PNG](../artifacts/task2_occupancy_grid.png)。

这里验证的是映射算法和数据接口，不是 G2 的 RTX LiDAR 实测，也没有把课程 `yolo26.gif` 当作本机检测结果。若补齐 Isaac Sim，应再记录相机/雷达话题、帧率、外参、模型权重、阈值和地图分辨率。
