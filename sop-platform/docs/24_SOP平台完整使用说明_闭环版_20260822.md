## 2. 角色职责

| 角色 | 主要工作 | 不得跳过的门禁 |
| --- | --- | --- |
| 操作员 | 选择工位/视频、查看实时 SOP、处理纠正提示 | 不修改模型和冻结数据集 |
| 标注员 | 修正 AI 候选、补框、删框、修 Track 和类别 | 不把未检查候选标为真值 |
| Reviewer | 检查标签口径、轨迹、遮挡、NG 和步骤边界 | 未达标必须驳回 |
| 算法工程师 | 构建数据集、训练、验证、注册和灰度部署 | 不用候选标签指标冒充量产精度 |
| MES/质量管理员 | 配置工艺规则、放行门禁、回执和审计 | 外部信号缺失时保持 HOLD |

账号初始凭据只在服务器权限受控文件中生成，不写入本文和 GitHub。

## 3. 日常闭环流程

### 3.1 02 数据获取与清洗

1. 选择 RTSP/UVC 实时源、Google Drive 增量源或本地历史视频。
2. 绑定工位、产品/SN、拍摄日期和采集来源。
3. 执行 ffprobe 完整性检查，确认时长、FPS、分辨率和编码可读。
4. 做 SHA256/文件 ID 去重，损坏和重复视频进入隔离区。
5. 对超大或浏览器不兼容视频生成 H.264 代理；原片保留，不覆盖。
6. 根据工位规则建立 ROI、抽帧策略和 VideoAsset 记录。

当前 Google Drive 接口使用 OAuth/rclone。禁止把 Google 账号密码写入脚本。17:00 全自动增量抓取尚未完成，现阶段应检查同步结果后再启动预标。

### 3.2 03 AI 预标注

1. 选择工位专用标签模板，不使用无约束总标签池。
2. 选择预标模型和抽帧范围。
3. 对固定物体使用检测/分割候选，对移动目标使用 Tracking/SAM2 候选。
4. 检查候选数量、类别分布和明显误框。
5. 将任务标记为“待人工复核”，不得直接进入正式训练。

### 3.3 04 CVAT 人工复核

1. 从 SOP 平台创建或打开绑定的 CVAT Task。
2. 标注员逐段检查 AI 框，可删除、移动、缩放、改类别、补框和调整关键帧。
3. 目标遮挡、转向、速度突变和步骤边界处增加关键帧。
4. 同一物体保持 Track ID 连续；跟踪漂移时分段修正，不保留错误传播。
5. 标注员保存后提交 Reviewer。
6. Reviewer 检查漏标、误标、类别混淆、NG 稀有样本和 SOP 步骤边界。
7. 审核不通过则驳回；通过后记录审核人、时间和 annotation version。

AI 预标进入 CVAT 后可以人工修改和删除，不需要退回纯人工从零标注。当前平台可向 CVAT 推送标注；CVAT Webhook 自动回拉仍待实现，现阶段需由管理员执行同步并核对版本。

### 3.4 05 数据集构建

1. 同步 annotation-only 文件，不导出每一帧 PNG 作为长期中间件。
2. 将原 MP4、annotation version 和 Frame Manifest 关联。
3. 按完整视频、产品 SN、工位或日期划分 Train/Val/Test，避免相邻帧泄漏。
4. 只在本阶段按需抽取 JPEG 缓存，并配置尺寸、质量和过期策略。
5. 运行类别分布、空标签、越界框、重复帧和路径完整性检查。
6. 冻结 Dataset Version、标签映射、SHA256 和拆分清单。

CVAT 导出“图片 + XML”导致容量膨胀时，应改用 annotation-only。带框视频只用于复核展示，不能替代训练标签。

### 3.5 06 训练、验证与部署

1. 选择已冻结数据集和模型。
2. 正式训练选择“人工确认真值”；候选预训练结果只能用于研究。
3. 配置 epochs、batch、输入尺寸、设备、随机种子和输出目录。
4. 启动训练并保存日志、代码提交、环境、数据集版本和基础权重哈希。
5. 在固定测试集上输出 Precision、Recall、mAP50、mAP50-95、NG Recall、P95 延迟和稳定性。
6. YOLO26N 作为实时基线；RT-DETRv2/D-FINE 做 Shadow 或离线交叉验证；PatchCore/EfficientAD 做事件触发异常检查。
7. 通过验收的模型进入 Model Registry，先灰度单工位，保留旧版本和回滚入口。

当前真实训练执行器支持 Ultralytics YOLO26/YOLOE。RT-DETRv2、D-FINE 和 Anomalib 的完整训练后端尚未交付，页面登记不等于已经训练成功。

### 3.6 07 实时 SOP 与 MES

1. 选择工位、Recipe、模型版本和 RTSP/UVC 摄像头。
2. 左侧确认实时画面、ROI、检测框、Track、FPS 和延迟。
3. 右侧确认当前步骤、标准动作、持续时间、置信度和纠正方法。
4. 将视觉证据与扫码枪、PLC、温度、扭矩/角度、打印机和 MES 指令按 SOP FSM 融合。
5. 顺序正确且全部门禁满足才输出 PASS；步骤错误、超时或关键目标缺失输出 NG/REWORK；证据或设备回执缺失输出 HOLD。
6. MES 回传必须包含工位、SN、Recipe、步骤、结果、时间、模型版本、证据 URI 和审计 ID。
7. 误报、漏报、低置信度和 NG 稀有样本进入 Hard Case 待审队列。

## 4. 网页标注与自动恢复

网页标注支持播放/暂停、逐帧、跳帧、时间轴、画框、移动缩放、关键帧、插值、自动跟踪、删除单框、删除整轨和删除轨迹区间。保存后数据写入 SQLite WAL；页面会创建恢复点并保留审计记录。

发生浏览器刷新或异常退出时，先使用“恢复自动缓存”，确认视频、帧号、草稿框和数据库轮次一致后再继续。不要在服务运行时只复制 SQLite 主文件而遗漏 WAL，备份应使用平台备份或 SQLite backup API。

## 5. 数据和容量规范

- 原始视频只存一次，优先进入 MinIO/NAS 或受控数据卷。
- annotation、Manifest、Dataset Version 和 Model Version 独立版本化。
- 可重建 JPEG 帧缓存不进入 Git，设置水位和生命周期。
- 视频、模型权重、SQLite/WAL、账号、Token 和摄像头凭据不进入公开仓库。
- 训练集、验证集和测试集按完整视频或 SN 隔离，不能随机拆相邻帧。
- 删除操作应保留审计事件，不直接静默抹除历史版本。

## 6. 公网与安全操作

`192.168.1.129` 是局域网地址。异地访问应采用企业 VPN 或固定域名的受控反向代理，并配置 TLS、MFA/强认证、角色权限、限流、日志和备份。临时隧道只能调试，不能作为生产入口。

安全测试前必须取得书面授权并明确目标、时间窗、允许手段和回滚责任。优先做依赖漏洞扫描、配置审计、认证授权测试、上传限制、API 越权、速率限制、备份恢复和日志检查。不要在无授权时扫描第三方公网资产。

## 7. 每日运行检查表

1. 检查 8096、8099、CVAT 和数据库健康状态。
2. 检查存储水位、摄像头在线率、FPS、延迟和时间同步。
3. 核对当日新增视频、重复/损坏文件和预标任务。
4. 核对待复核、被驳回和已冻结的标注版本。
5. 核对训练任务、GPU、测试集版本和模型注册状态。
6. 核对 MES ACK、NG/REWORK/HOLD 和未闭环报警。
7. 审核 Hard Case，去重后分配到下一轮标注。
8. 检查数据库、配置、标注版本和模型注册表备份。

## 8. 验收标准

交付验收必须附：人工审核人、冻结数据集版本、拆分规则、模型哈希、阈值、测试报告、P95 延迟、8 小时稳定性、断网补传、设备掉线、模型回滚、MES ACK 和备份恢复记录。

自动候选数量、带框演示视频和页面上显示的模型名称都不能替代上述验收证据。没有完成人工真值、同条件对比和现场联调时，量产状态保持 `HOLD`。
