# 8113 离线完整交付包使用说明

## 1. 包的用途

离线包用于在同架构 ARM64 Linux 工控机或服务器上恢复 SOP 8113、CVAT 2.73.1 中文界面、MediaMTX 相机网关和已登记的模型资产。包内大文件均为真实镜像、源码或模型，不使用无意义填充。Windows 浏览器可访问服务，但 ARM64 Docker 镜像不能直接在普通 AMD64 Windows Docker 主机运行。

## 2. 目录内容

- `source/`：8113 Git 源码快照和 CVAT 2.73.1 源码包。
- `docker-images/`：当前 ARM64 部署所需镜像的 Docker Save 文件及镜像清单。
- `models/`：YOLO26N、YOLOE-26S、YOLOv8s-World v2、RT-DETRv2、D-FINE 和 MobileCLIP 等本机模型资产。
- `documents/`：Markdown、Word、发布报告和浏览器验收记录。
- `manifests/`：文件清单和 SHA256。

密码、恢复码、CVAT Token、Webhook Secret、SQLite/WAL、视频和相机录像不在公开离线包中。账号通过同级私密文件单独交付。

## 3. 恢复顺序

1. 用 `sha256sum -c manifests/SHA256SUMS.txt` 校验文件。
2. 用 `docker load -i docker-images/cvat-mediamtx-arm64-20260823.tar` 导入镜像。
3. 解压 `source/cvat-2.73.1-source.tar.gz`，检查并按现场路径调整 Compose 卷挂载。
4. 解压 `source/sop-polished-20260823-8113-source.tar.gz` 到受控代码目录。
5. 创建独立运行目录和权限 `600` 的环境文件，配置初始密码、恢复码、CVAT Token 和 Webhook Secret。
6. 根据 `sop-platform/deploy/systemd/sop-polished-8113.service.example` 修改路径后安装服务。
7. 启动 CVAT、MediaMTX 和 SOP，再验证 `8081`、`8113`、`8554`、`8888` 和 `9997`。
8. 在 Chrome 中登录，检查 01 至 07 页面、视频 Range、三路相机、修改密码和忘记密码。

## 4. 冻结要求

恢复或升级时不得覆盖 `8102`、`8112` 或其他已验收版本。每次新版本都要使用新分支、新端口、新运行目录和独立 SQLite。模型文件只能说明后端资产存在，不能替代人工真值、固定测试集和现场长稳验收。
