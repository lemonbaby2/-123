## 2. 功能验收结果

### 2.1 视频与导入

- 视频目录共 23 段，`23/23` 均能由受控媒体解析器找到并通过 HTTP Range 播放。
- Chrome 中监控视频和标注视频均达到 `readyState=4`，分辨率均为 1280×720。
- Pocket 3/SD 卡采用只读导入，任务进度自动轮询；成功后自动刷新视频目录和 AI 预标队列。
- AI 预标状态能识别全部 23 段视频，无缺失视频 ID。

### 2.2 三种导出

- 轻量 annotation-only ZIP：保存坐标、审核记录、版本和 Frame Manifest，不重复打包原 MP4。
- 全帧带框 JPEG ZIP：实测 344 帧，文件大小 28,672,323 字节，ZIP 完整性检查通过。
- 完整带框 H.264 MP4：实测文件大小 3,712,093 字节，时长 22.933333 秒，`ffprobe` 检查通过。
