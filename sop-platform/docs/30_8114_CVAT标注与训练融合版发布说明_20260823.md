## 6. VPN 代理与访问

`all_proxy=http://127.0.0.1:7890` 是出站代理，不会把局域网站自动发布到公网。代理进程未监听时直接导出该变量，会导致终端和 VS Code 网络请求失败。

本机 Bash 和 VS Code 已配置 `NO_PROXY/no_proxy`，绕过 `localhost`、`127.0.0.1`、`192.168.1.129`、整个 `192.168.1.0/24` 和本机 Docker 网段。新终端使用：

```bash
source ~/.bashrc
sop_proxy_on
sop_proxy_off
```

`sop_proxy_on` 会先检查 7890，未监听时拒绝修改代理变量。不要再单独执行裸 `export all_proxy=...`。

若 VPN 使用 TUN 全局路由，还必须在 VPN 客户端打开 Allow LAN/允许局域网，并确保 `192.168.1.0/24` 走本地网关。异地访问需要固定企业 VPN、反向代理或稳定隧道；匿名 localhost.run 域名会轮换，不能作为生产域名。
