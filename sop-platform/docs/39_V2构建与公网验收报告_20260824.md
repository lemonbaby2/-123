## 四、架构结论

中心机继续运行唯一一套 SOP、CVAT、数据、训练与 MES 服务；员工电脑只安装 V2 客户端。这样每个人看到的是同一批任务、同一套标注、同一模型版本和同一 MES 记录，不会形成“每台电脑一份数据”的孤岛。

公网链路为：

```text
外网浏览器 / V2 客户端
        ↓ HTTPS
Cloudflare 边缘网络
        ↓ 出站加密 Tunnel
中心机 cloudflared
        ├─ SOP  127.0.0.1:8113
        └─ CVAT 10.70.102.210:8081（Host 重写）
```

中心机无需开放公网入站端口，也不需要路由器端口映射。

## 五、上线前剩余外部条件

代码与本机部署已经完成；要把随机临时网址升级为固定生产网址，仍需业务方提供：

1. Cloudflare 账号；
2. 托管在 Cloudflare DNS 的正式域名；
3. Named Tunnel Token；
4. 最终子域名，例如 `sop.公司域名`、`cvat.公司域名`、`mes.公司域名`；
5. 允许访问的企业邮箱或身份提供商规则。

取得以上信息后，应安装 Named Tunnel Windows 服务、配置开机自启、Cloudflare Access 双层鉴权和断线告警，再进行正式投产。
