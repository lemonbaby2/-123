# 8116 分布式预标注与温控版发布验收报告

版本：2026-08-23

SOP 平台：`http://192.168.1.129:8116`

代码分支：`sop-distributed-prelabel-20260823-8116`

## 1. 发布边界

8116 是 8115 的独立后继版本。8102、8113、8114、8115 和 CVAT 数据均未覆盖。8116 使用独立 runtime、人工标注 SQLite、AI 候选 SQLite、账号会话和私有环境文件。AI 候选始终为 `pending_review`，本报告不把自动框数量等同于人工真值或量产精度。

## 2. 本版功能

- 以完整视频为租约单位的 worker 注册、领取、批次提交、完成和失败重试 API。
- 工位级粗粒度标签模板，默认排除电阻、电容、电感、芯片和细小焊点等微小元件。
- AI 候选库与人工审核/账号库分离。
- batch 4、640 输入、低调度优先级、CPU 配额、每批冷却和 70/62°C 温控回差。
- 页面显示总帧、完成帧、在线节点、节点温度、队列和 `pending_review` 边界。
- 暂停在当前批次后生效，恢复优先续跑暂停视频。
- 当前画面缓存用于框点击命中，避免点击时重复筛选和坐标映射。
- 自动恢复点只在草稿变化后提交，物理 SQLite 自动备份五分钟限频并串行执行。
- 总览加入完整技术栈架构图和交付能力带。

## 3. 验收结果

### 3.1 小视频全帧预标

`video_nb0819_01` 共 344 帧，完成 344 帧状态和 730 个工位级候选。排除标签命中 0，非 `pending` AI 候选 0。标注 ID 包含视频 ID，不会与其他视频同帧结果冲突。

### 3.2 温度与资源

小视频运行期间观测 GPU 为 50–53°C，明显低于 70°C 暂停阈值。worker 配置 `Nice=15`、`CPUWeight=10`、`CPUQuota=150%` 和 `IOSchedulingClass=idle`。阈值保护不能替代机房风道、散热器和长稳验收。

### 3.3 暂停恢复

`video_de02` 在第 1928 帧暂停，恢复后从第 1928 帧继续。修正队列优先级后，`video_d66` 在第 568 帧暂停并被优先续领。已提交帧没有清空或重复增加。

### 3.4 浏览器

Playwright 在 1440×1000 和 390×844 视口通过。架构图自然宽度 1491 px；默认工位级筛选、展开全部、重置筛选和移动端宽度均通过。画布真实框命中耗时 2.1 ms，目标小于 50 ms。HTTP 错误和控制台错误均为 0。

### 3.5 自动恢复点

连续两次自动保存中，第一次更新物理数据库备份，第二次复用五分钟内备份；人工保存仍立即更新备份。该结果验证了限频逻辑，浏览器无草稿变化时还会在请求前直接跳过。

## 4. 后台状态

通过 344 帧验收后已解除单视频限制，worker 以低优先级逐段处理剩余队列。页面上的完成帧和节点温度为实时值，不能把发布时的瞬时数值写成最终固定结果。发生 70°C 温控暂停、三次失败或源视频缺失时，任务应保持暂停/失败，由管理员查日志后处理。

## 5. GitHub 和大文件

GitHub 分支只包含源码、配置模板、文档、QA 报告和必要页面资产。公开仓库不包含生产视频、模型权重、SQLite/WAL、账号文件、恢复码、CVAT Token、worker token 或相机凭据。GitHub 普通 Git 单文件限制为 100 MB；大模型和视频应放私有对象存储、受控 Release/LFS 或现场数据盘，并记录 SHA256。
