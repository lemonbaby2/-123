# 宁波视觉 SOP + CVAT 一体化工作台 V2 与公网部署说明

日期：2026-08-24  
适用版本：V2 增量交付  
原则：旧网页、旧 EXE、旧安装包和现有业务数据全部保留，不覆盖、不迁移。

## 1. 本次实现结果

新增“一体化工作台 V2”，把现有能力按业务顺序组织为：

1. 运营总览；
2. 数据接入；
3. 清洗质检；
4. AI 预标注；
5. CVAT 人工标注；
6. 数据集冻结；
7. 模型训练；
8. 推理验证；
9. 实时 SOP；
10. MES 闭环。

V2 不是另起一套数据库。多台电脑登录后仍使用中心机上的账号、SQLite 数据、视频、标注、训练任务、模型和 MES 记录。旧功能页面通过同源工作区加载，原权限和操作能力继续生效；官方 CVAT 因安全响应头禁止 iframe，桌面端会以同一软件内的独立 CVAT 子窗口打开。

## 2. 旧网页冻结保护

以下旧文件没有修改：

- `web/index.html`
- `web/app.js`
- `web/styles.css`

基线 SHA256 已写入 `web/unified/legacy-manifest.json`。执行下面命令可随时检查：

```powershell
pwsh -ExecutionPolicy Bypass -File .\scripts\Test-LegacyWebIntegrity.ps1
```

V2 新网页位于 `web/unified/`，旧入口仍可继续使用。

## 3. 局域网使用

中心服务：

- SOP：`http://10.70.102.210:8113`
- V2 网页：`http://10.70.102.210:8113/unified/`
- CVAT：`http://10.70.102.210:8081`

同一局域网的电脑安装 V2 客户端即可。客户端默认连接以上中心地址；如果 IP 改变，在客户端连接页填写新的 SOP 与 CVAT 地址，配置保存在 `%LOCALAPPDATA%\NingboSOPUnified\client.json`。

## 4. Quick Tunnel 公网验收

本机已安装 Cloudflare 官方 `cloudflared`。以普通 PowerShell 运行：

```powershell
pwsh -ExecutionPolicy Bypass -File .\scripts\Start-CloudflareQuickTunnel.ps1
```

脚本会生成 SOP、CVAT 和带 CVAT 参数的一体化入口，并把 PID、网址与日志保存到：

```text
%LOCALAPPDATA%\NingboSOPUnified\cloudflare-quick\quick-tunnel-state.json
```

停止本工具启动的两个隧道：

```powershell
pwsh -ExecutionPolicy Bypass -File .\scripts\Stop-CloudflareQuickTunnel.ps1
```

注意：Quick Tunnel 的随机域名会在重启后变化，没有 SLA，最多 200 个并发中的请求且不支持 SSE，只用于测试、演示和临时验收。不要把随机地址写入 MES、摄像机或长期书签。

## 5. 正式 Named Tunnel 方案

正式环境需要用户提供以下外部资源：

- Cloudflare 账号；
- 已接入 Cloudflare DNS 的自有域名；
- Named Tunnel Token，或本地管理 Tunnel 的 UUID 与凭据 JSON；
- 计划使用的子域名，例如 `sop.example.com`、`cvat.example.com`、`mes.example.com`。

一个 Named Tunnel 可以发布多个 hostname。模板位于 `deploy/cloudflare/config.named.example.yml`，其中：

- `sop.example.com` → `http://127.0.0.1:8113`
- `cvat.example.com` → `http://10.70.102.210:8081`
- `mes.example.com` → `http://127.0.0.1:8113`

当前 CVAT 使用 Traefik Host 路由，CVAT 项必须配置 `httpHostHeader: 10.70.102.210`，否则公网访问会返回 404。

生产实施顺序：

1. Cloudflare Zero Trust → Networks → Tunnels 创建 remotely-managed Named Tunnel；
2. 在 Public Hostname 中配置三个 hostname 与源站；
3. 在中心机以管理员身份执行控制台给出的 Windows 服务安装命令；
4. 服务设为自动启动，并验证重启后隧道恢复；
5. 为 SOP 和 CVAT 配置 Cloudflare Access 身份策略（企业邮箱、一次性 PIN 或身份提供商）；
6. 在 Access 后继续保留 SOP/CVAT 自身账号，形成双层鉴权；
7. 配置断线告警、访问日志、定期更新与凭据轮换。

正式生产不建议“全网任何人无需验证即可打开登录页”。公网可达与无限制匿名访问是两件事；建议只允许公司员工、项目客户或指定邮箱域通过 Cloudflare Access。

## 6. Windows 客户端安装与使用

安装 `宁波SOP_CVAT一体化工作台_V2_安装程序_20260824.exe`。安装后：

1. 局域网电脑会自动连接中心机；
2. 外网电脑首次打开时填写正式 SOP/CVAT HTTPS 域名；
3. 使用原 SOP 岗位账号登录；
4. 点击左侧 01—10 按业务流程操作；
5. 在“CVAT 人工标注”先完成任务交接，再点“打开官方 CVAT”；
6. 工人、管理者、开发者继续遵循原有权限，不因公网入口而提权。

## 7. 运维与安全清单

- 中心机必须持续运行 SOP、WSL/CVAT 和 cloudflared 服务；
- 不对路由器开放 8113/8081 公网入站端口；
- 正式域名启用 Cloudflare Access、MFA、访问日志与断线告警；
- 修改首次交付密码，不在文档、脚本或聊天中传播生产密码；
- 数据集大文件上传需注意 Cloudflare 单请求限制，优先分片或在局域网完成；
- CVAT、SOP 与 MES 备份仍在中心机执行，Tunnel 不是备份系统；
- Windows 上 cloudflared 不自动更新，应纳入月度运维。
