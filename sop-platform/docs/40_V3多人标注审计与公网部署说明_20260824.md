# 宁波视觉 SOP 多人标注与决策平台 V3

版本：2026.08.24.3
适用对象：项目负责人、产线工程师、数据管理员、标注员、模型工程师和 MES 对接人员。

## 1. 本版本解决的问题

V3 在保留原 8113 SOP 页面、原 CVAT 页面和既有数据的前提下，新增一套独立的多人协作入口。它把“数据获取—任务分配—CVAT 标注—数据清洗—训练—验证—实时 SOP—MES 回传”按业务顺序放在同一导航中。

系统不会把 CVAT 替换成简化标注页面：画框、轨迹、属性、关键帧和 Review 仍在官方 CVAT 中完成；SOP 平台负责任务编排、人员归属、训练/验证入口、结果汇总和审计。

## 2. 页面顺序

1. 多人协作：查看五名标注员、分配视频、检查进度和操作记录。
2. 项目总览：查看产线、相机、模型和放行状态。
3. 数据获取与清洗：导入视频、抽帧、去重、模糊帧筛除和数据集版本管理。
4. 分布式预标注：中心机拆分任务，GPU 节点领取分片并回传候选框。
5. SOP 人工标注：逐帧修订候选框，保存操作人与审核人。
6. CVAT 专业标注：打开官方 CVAT 任务、Job 和 Review 工作区。
7. 数据质检：检查漏标、错标、类别不一致和小目标质量。
8. 三模型训练：选择产线、数据版本、模型、轮数和显卡参数。
9. 模型验证：比较 Precision、Recall、mAP50、mAP50-95 和小目标指标。
10. 实时 SOP：左侧显示检测画面，右侧显示六步 SOP 和异常告警。
11. MES 回传：配置工位、工单、工序、结果码和重试策略。

## 3. 账号和数据归属

平台预置管理员、项目管理员、普通员工和五名标注员。初始密码属于部署凭据，只在离线交付目录的《账号密码_仅本地.txt》中提供，不写入公开 GitHub、安装包源码、日志或接口响应。

每次分配均记录标注员、视频、状态、备注、分配人和时间。人工标注写入 `operator`，审核写入 `reviewer`；普通标注员只能查看自己的操作记录，管理员和项目管理员可以查看全员记录。

## 4. CVAT 双向同步

- SOP → CVAT：将视频/抽帧数据、标签规范和候选框发送到指定 Task。
- CVAT → SOP：只拉取 annotation JSON、Frame Manifest 和审核状态，不重复导出原始视频。
- Webhook：CVAT 的任务、Job、Issue、Comment 事件经 HMAC-SHA256 验签后写入统一审计库。
- 安全：CVAT Token 和 Webhook Secret 仅放在服务器运行目录，禁止打入安装程序或上传 GitHub。

当前验收环境已建立独立的 CVAT 审计项目及 Webhook。Quick Tunnel 地址可能在重启后变化；变化后需要更新 CVAT Webhook 的目标 URL。正式生产应改用固定域名的 Cloudflare Named Tunnel。

## 5. 部署结构

```text
员工电脑（V3 EXE/浏览器）
        │ HTTPS/LAN
        ▼
SOP V3 中心服务 :8117 ── SQLite 统一任务/审计库
        │                       │
        ├── CVAT :8081          ├── 分布式预标注 GPU 节点
        ├── 原 SOP :8113        └── MES 接口/重试队列
        └── Cloudflare Tunnel（公网入口）
```

V3 客户端只是连接入口，不在每台员工电脑重复保存中心数据库。所有人使用同一中心服务，才能看到一致的任务、标注进度和审计记录。

## 6. 服务器启动

在中心机 PowerShell 中执行：

```powershell
& '.\scripts\Start-SOPV3Server.ps1'
```

停止 V3：

```powershell
& '.\scripts\Stop-SOPV3Server.ps1'
```

脚本只管理 V3 的 8117 端口，不终止原 8113 SOP、8081 CVAT 或旧版公网隧道。

## 7. 公网测试与正式公网

验收测试可执行：

```powershell
& '.\scripts\Start-V3QuickTunnel.ps1'
```

Quick Tunnel 是临时地址，适合演示和验收。正式环境应使用 Cloudflare Named Tunnel，并建议配置：

- `sop.example.com` → `http://localhost:8117`
- `cvat.example.com` → `http://localhost:8081`

生产环境还应启用 HTTPS Secure Cookie、Cloudflare Access/企业身份验证、固定域名、访问策略和备份监控。

## 8. Windows 客户端安装

运行《宁波SOP多人标注与决策平台_V3_安装程序_20260824.exe》。首次启动默认连接局域网中心地址；不通时会显示连接设置页，可填写局域网或公网地址。

安装程序不内置数据库、Token 或 Webhook Secret，因此可以安全分发给员工。客户端配置保存在当前 Windows 用户的 `%LOCALAPPDATA%\NingboSOPUnifiedV3\client.json`。

## 9. 旧版保护与回退

V3 是增量入口，未覆盖以下旧版文件：

- `web/index.html`
- `web/app.js`
- `web/styles.css`

它们的冻结 SHA-256 保存在 `web/unified-v3/legacy-manifest.json`。发布前运行 `scripts/Test-V3Release.ps1`，任何旧文件字节变化都会导致检查失败。

如 V3 暂不可用，员工仍可直接访问原 8113 SOP 和 8081 CVAT，业务不会因 V3 客户端升级中断。

## 10. 上线后必须持续完成的工作

1. 将临时公网地址换成固定域名 Named Tunnel。
2. 按岗位修改初始密码，不长期共用密码；管理员启用强密码和二次认证。
3. 每日备份 SQLite、CVAT 数据库、标注导出和模型注册表，并定期恢复演练。
4. 每周检查漏标、错标、小螺钉召回率和不同光照/工位的数据漂移。
5. 新模型先进入候选版本，经现场验证和负责人签字后再切换生产模型。
6. MES 接口需完成超时、断网缓存、幂等、补传和追溯编号验收。
7. 摄像机位置、焦距或照明变化后重新做视场和精度验收。

## 11. 验收标准

- 五名标注员均能独立登录并只看到自己的工作记录。
- 管理员可以分配视频，并实时看到人员进度和最近操作。
- CVAT Task/Job 可访问，SOP 与 CVAT 绑定关系可查询。
- CVAT Webhook 验签成功，操作进入统一审计库。
- 原 8113 SOP、8081 CVAT、V3 8117 同时在线。
- Windows 安装程序可独立安装、启动、连接和卸载。
- 旧版冻结文件哈希一致，发布包附带 SHA-256 校验清单。
