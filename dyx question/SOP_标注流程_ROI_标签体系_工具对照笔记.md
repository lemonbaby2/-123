# SOP 标注流程、ROI 口径与工具分工笔记

## 1. 当前项目到底是不是先 AI/YOLOE 预标注

是。当前这套 SOP 项目走的是：

1. 离线先用 `YOLOE-26S` / `YOLOv8-World` / `SAHI` 做自动预标注；
2. 再由人工逐框确认、收紧边框、删除误报、补漏；
3. 质量人员抽检后，才进入正式训练集。

相关目录和文档里都明确写了“待人工复核”“自动预标注不是人工真值”。

## 2. ROI 标注到底是什么

这里的 ROI 更接近“固定相机下的业务区域/步骤区域”。

- 对固定相机方案，ROI 是先标定一次、后续每帧复用的区域；
- 它用于限定步骤区、零件区、检测关注区；
- 但 ROI 不是“只画区域就结束”，ROI 内仍然要做目标框标注或候选框复核；
- 对小目标候选，系统会先在 ROI 内做切片，再输出候选框，人工继续确认。

换句话说，ROI 是外层范围，目标框是真值主体。

## 3. 新视频有没有统一标签体系

有，当前新视频使用的是统一的 12 类细粒度标签体系，全部还是 `待人工复核`：

1. 仪表板总成
2. 仪表板骨架
3. 饰板总成
4. 线束
5. 电气接插件
6. 电动紧固工具
7. 操作人员手部
8. 螺钉头候选
9. 螺栓头候选
10. 塑料卡扣候选
11. 线束插头候选
12. 紧固孔候选

## 4. 后续用什么工具解决什么事情

| 事情 | 工具 |
|---|---|
| 自动发现候选框 / 预标注 | `YOLOE-26S`、`YOLOv8-World`、`SAHI` |
| 逐框修正、删除、补漏 | `CVAT` / `Label Studio` |
| 视频跟踪、跨帧保持 ID | `BoT-SORT`、`OC-SORT` |
| 小目标放大识别 | `SAHI` 切片推理 |
| 视频分割 / 掩膜传播 | `SAM 2`、`Grounded-SAM-2` |
| 闭集量产模型训练 | `YOLO26` / `YOLOv8` + `PyTorch` |
| 部署与推理优化 | `ONNX`、`TensorRT`、`Triton` |
| 视频采集、编码、事件片段输出 | `OpenCV`、`GStreamer`、`FFmpeg` |
| 数据集版本管理 | `DVC` + `Git` |
| 实验记录与模型版本 | `MLflow` |
| 数据浏览和抽检 | `FiftyOne` |
| 格式转换 | `Datumaro` |
| 现场 SOP、MES、设备联动 | `FastAPI`、`MQTT`、`OPC UA`、`Modbus`、`pyserial` |

## 6. 这份项目里最关键的结论

- 不是纯人工先标，而是 AI 先出候选，人工收敛成真值；
- ROI 是固定相机下的业务区域，不是替代目标框；
- 新视频已经有统一标签体系，但目前仍全部待复核；
- 量产放行不能只看视觉结果，必须和扭矩、角度、MES 回执一起看。
