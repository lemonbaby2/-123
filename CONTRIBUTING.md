# Contributing

Keep contributions reproducible, privacy-safe, and license-compatible.

1. Do not submit employer/customer code, datasets, credentials, maps, or model weights.
2. Add a deterministic unit test for behavior changes.
3. Record the source and license of every external algorithm or asset.
4. Separate resume-reported metrics from metrics produced by this repository.
5. Run `python -m unittest discover -s tests -v` before opening a change.
