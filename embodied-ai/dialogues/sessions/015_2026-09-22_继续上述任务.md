## 一个必须先接受的硬事实

**ROS 2 的发行版和 Ubuntu 版本是 1:1 绑定的，Humble 在 24.04 / 26.04 上没有官方 apt 包。**

我直接从清华镜像的包索引里抓证据（不是推测）：

| Ubuntu | 代号 | 官方 ROS 2 | 镜像索引里实际有什么 |
|---|---|---|---|
| 22.04 | jammy | Humble | `ros-humble-desktop` ✅ |
| 24.04 | noble | Jazzy | **只有 jazzy / kilted / rolling，没有任何 humble 包** |
| 26.04 | resolute | **Lyrical Luth** | **只有 ros-lyrical-desktop** |

所以「把所有命令调配成三个版本都能跑」的解法不是改命令，是**把发行版名变成变量**：

```bash
for d in /opt/ros/*/setup.bash; do [ -f "$d" ] && source "$d"; break; done
sudo apt install -y ros-${ROS_DISTRO}-xacro
```

同一份教案、同一份学生代码，三个版本一律不用改。

3. **DNS 抖动自动重试 3 次** + 新增 **`--doctor` 逐层体检**（出网 → 解析 → 每地址连通 → TLS 与时间 → 站点 200）与 `--ipv4`。
