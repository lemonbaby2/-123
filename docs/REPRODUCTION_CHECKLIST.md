# 系统复现与实机验收清单

## 数据与标定

- [ ] 原始数据只读归档并记录 SHA-256。
- [ ] 相机内外参、LiDAR-IMU/RTK 外参和时间偏移均有版本号。
- [ ] 训练/验证/测试按场景隔离，防止相邻帧泄漏。
- [ ] 动态、弱纹理、强光、遮挡、振动、低温等边界场景有单独分组。

## 软件与硬件

- [ ] 固定 OS、ROS2、CUDA、TensorRT、驱动、固件和模型版本。
- [ ] 记录 Jetson 功耗模式、频率锁定、温度、预热次数与后台负载。
- [ ] MCU 记录编译器、优化级别、Flash/RAM、栈水位和最坏执行时间。
- [ ] 每次实验保存配置、Git commit、命令、随机种子和日志。

## 指标

- [ ] SLAM：ATE/RPE、丢跟踪次数、回环误检率、10/50/95/99 分位延迟。
- [ ] 检测：AP50-95、每类 precision/recall、漏检率、误报率和置信区间。
- [ ] 量化：FP32/FP16/INT8 同一评测集精度、延迟、峰值显存和功耗。
- [ ] BMS：SOC MAE/RMSE/max error、不同温度/倍率/老化程度、收敛时间。
- [ ] 通信：有效载荷吞吐、丢包、CRC 错误、重连时间和带宽余量。

## 安全与降级

- [ ] 断网、ROS master/daemon 异常、定位失效、地图缺失时禁止运动命令。
- [ ] 传感器超时、时间倒退、NaN/Inf 和外参缺失可检测。
- [ ] 有物理急停、独立速度限制、看门狗和可审计操作日志。
- [ ] WebSocket/HTTP 启用 TLS、认证、权限控制、CSRF/CORS 策略和限流。

## 报告格式

结果表必须包含：版本、样本数、均值、中位数、P95、最差值、置信区间、失败样例、已知限制。历史简历数字与重新复现数字不得合并。
