# Third-party references and license notes

No third-party source code, model weights, datasets, resume PDF, or paper PDFs are vendored in this repository. Links in `RESEARCH.md` are references only.

Before incorporating an external implementation, create a software bill of materials containing project URL, exact commit/version, license, notices, modifications, model-weight terms, dataset terms, and commercial-use decision.

High-attention items:

- GraphDeco Gaussian Splatting reference code: research/evaluation, non-commercial restrictions in its custom license.
- Ultralytics: AGPL-3.0 or enterprise license depending on use.
- ORB-SLAM3: GPL-3.0.
- Datasets such as MVTec AD may impose non-commercial or redistribution restrictions.
- NVIDIA TensorRT: NVIDIA SDK license terms apply.
- ISO standards: the full standard text is copyrighted and is not redistributed here.

The MIT license at the repository root applies only to original code and documentation authored for this portfolio.
